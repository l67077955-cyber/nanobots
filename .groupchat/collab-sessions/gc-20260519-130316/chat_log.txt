## 今日代码变更拆解

### 保留的（8c02692 留下的）：

**1. Compact 模式 — loader.py `load_skills_for_context()` 新增 `compact=True` 分支**
- 当启用时，always-on skill 不再完整嵌入 SKILL.md，改为一行描述 + `[read_file]` 指针
- **效果**: 每次 agent 上下文节省 ~40% skill text 篇幅。合理优化，无副作用。

**2. Docless skill 发现 — list_skills() 检测无 SKILL.md 但有 scripts/ 的目录**
- 条件：dir 存在 `scripts/` 且包含 `.py/.sh` → 标记 `docless: True` 纳入 skill 列表
- 纯边缘 case 补漏，对当前配置是干净的话 → **no-op**

**3. Untracked 脚本发现 — `_discover_untracked_scripts()` 新方法**
- 扫描 `workspace/skills/` 根目录下的独立 `.py/.sh` 文件（不属于任何 skill dir）
- **大概率 no-op** — 除非你们在 skills/ 根放了独立脚本

**4. Truncation 行边界修复 — `load_skills_for_context()` 截断改走 `rfind('\n')`**
- 之前截断可能卡在行中间，现在是行边界。纯 polish。

**5. DNS 解析松弛 — network.py 一行改动**
-  ```diff
  -return False, "Cannot resolve hostname: {hostname}"
  +return True, "...allowed through (unreachable)"
  ```
- 不可达 host **不再拦截**，改为放行并标记。**改变安全语义**，得确认这是不是你们想要的。

**6. 8 个 SKILL.md frontmatter + always: false**
- 标准统一，无行为变化。

**7. `_parse_bool()` dead return 清理 + docstring strip 微调**
- 零行为变化。
