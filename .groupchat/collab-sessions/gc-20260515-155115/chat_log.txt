你每次跟 AI 对话，系统会把**系统提示词 + 历史对话 + 你的问题**打包发给 API。如果连续多次请求的**开头部分完全一样**，API 提供商（如 SiliconFlow）会缓存这部分计算结果，下次直接复用——**不重复计费、不重复计算**。

### 问题出在哪？

**user_question（你的问题）被错误地塞进了"稳定前缀"里。**

```
修复前：
[系统提示词] + [你的问题] + [历史对话] + [你的问题]
 ↑────── 前缀 ──────↑

```

```

[系统提示词] + [历史对话] + [你的问题]
```

### 为什么 AI 不会搞混？

4. **有明确标记** — 当前问题后面跟着 `[Round: N]` 和日期时间，和历史里的普通 user 消息不一样。

def send_photo(filepath, caption):
    """Send photo using multipart upload to Telegram Bot API sendPhoto."""
    import http.client
    import mimetypes
    
    boundary = "----WebKitFormBoundary7MA4YWxkTrZu0gW"
    
    # Read file
    with open(filepath, "rb") as f:
        file_data = f.read()
    
    filename = os.path.basename(filepath)
    
    # Build multipart body
    body = []
    
    # chat_id field
    body.append(f"--{boundary}\r\n")
    body.append('Content-Disposition: form-data; name="chat_id"\r\n\r\n')
    body.append(f"{chat_id}\r\n")
    
    # caption field
    body.append(f"--{boundary}\r\n")
    body.append('Content-Disposition: form-data; name="caption"\r\n\r\n')
    body.append(f"{caption}\r\n")

            return True
    except urllib.error.HTTPError as e:
        print(f"  ❌ {filename}: HTTP {e.code} {e.read().decode()[:200]}")
        return False
