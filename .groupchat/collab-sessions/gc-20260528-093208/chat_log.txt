[Harper]: 因为设计上它就是两条独立的路径。

**工具调用路径**（Telegram 可见）：
```
agent → tool_loop → memory_palace.py → ChromaDB
                  ↘ engine.py (渲染 🟡→🟢) → Telegram
```

**轮询路径**（Telegram 不可见）：
```
run_loop.py → auto_recall_memories() / auto_store_memories()
           → L3.search() / tool_add_drawer()
           → ChromaDB
           ↘ logger.info() → 服务器日志
```

轮询不走 `tool_loop`，所以不经过 `engine.py` 的工具结果渲染，自然没有 Telegram 消息。要让它在 Telegram 可见，就得在 `run_loop.py` 里手动塞一条消息——但每轮群聊前后各一条，噪音不小。
