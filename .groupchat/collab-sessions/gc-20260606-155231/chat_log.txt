[Harper]: 因为你（或团队）最后执行了：

```bash
git checkout upstream-main
# 或者
git reset --hard upstream-main
```

导致 HEAD 指针从你的 `dev`（或 `stable-20260527`）切换到了 `upstream-main`（官方镜像）。

## 为什么会发生

可能是在某个操作中（如拉取官方最新代码、重命名分支、或者解决 merge 问题后 reset），HEAD 被绑到了官方分支上，而不是你的开发分支。

## 如何切回 dev

```bash
git checkout dev
```

这样 HEAD 就回到你的开发分支了。`upstream-main` 和 `dev` 是两个独立分支，不会自动同步。

---

如果你希望保持 `dev` 为默认分支，可以在 GitHub 设置里把 `dev` 设为主分支，替代当前的 `main`。
