[Kirk]: ## 改了什么

5/18-5/19 共 **11 commits**，改了两件事：

### 1. Prompt Phase System（5/18，9 commits）

把 19 个 prompt 组件从扁平结构改为 **static/dynamic 分层**：

- **static（11个，history 之前）**：main_prompt, persona, hard_rules, tool_instructions, skills, user_context, broadcast_hint, group_context, memory, output_efficiency, instructions
- **dynamic（6个，history 之后）**：leader_prompt, history, skills_overview, examples, group_nudge, coding_principle, 记忆补充

核心 commit `2363adb`：`COMPONENT_PHASES` 字典替代隐式 `past_history` 标志。效果是 history 之前的 static 前缀稳定不变，**prefix caching 可用**。

### 2. Skill 上下文压缩（5/19，2 commits）

- compact 模式：大技能只发 description + `read_file` 指针
- 行边界截断：不在词中断开
- docless skill 发现：无 SKILL.md 但有 scripts/ 的目录也被识别

### 3. 本轮额外修复

`loader.py:60` 加 `compact=True`，4 个 always-on 技能从 2800→673 chars，**省 2148 chars**。

### 结论

**不存在膨胀问题。** 改动方向是反膨胀。唯一膨胀源是 history 线性增长，由 `maybe_compress` 控制，与这两天改动无关。
