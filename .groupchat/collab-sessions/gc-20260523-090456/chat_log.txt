[Kirk]: ## 结论

**当前所有 agent 共享完全相同的上下文，包括彼此的工具调用细节。** 不需要独立上下文——在已有的 `history_to_messages` 过滤链路上加 rank-based 工具调用剥离即可，改 3 个文件。

## 关键发现

1. **工具调用记录格式**：`[工具调用记录]\n• 工具名(参数) → 预览 (字数)`，由 `build_tool_log()` 拼接到消息 content 里（`broadcast.py:1005`）
2. **过滤入口已存在**：`message_converter.py:83` 有 `relevant_agents` 白名单，但只过滤整条消息，不能做到"保留文字、剥离工具调用"
3. **最小改动方案**：在 `history_to_messages` 中加正则剥离 `[工具调用记录]` 段落，按 rank 规则决定是否剥离

## 实现方案

**rank 越小权限越高**（0=Leader, 1=Senior, 2=Worker）。Agent 只能看到 rank ≤ 自己的 agent 的工具调用。文字消息（chatroom_send）不受影响。

| 改动文件 | 内容 |
|---|---|
| Agent config | 加 `rank` 字段 |
| `message_converter.py` | 加 `strip_tool_log()` 正则函数 + rank 比较逻辑 |
| `engine.py` / `broadcast.py` | 传递 `agent_ranks` 字典到 `history_to_messages` |

**效果**：Leader 上下文最干净（只有自己的工具调用 + 所有人的文字结论），Worker 上下文最完整（能看到所有上级的工具调用细节）。
