[用户]: 为什么有分这么多文件呢

[Harper]: 分这么多文件是**渐进式加功能，没做清理**的结果。

演变过程：

```
v1: prompt_order.json          ← 只有"顺序"，一个列表就够了
v2: + prompt_visibility.json   ← 新增"每个section是否对所有人可见"的需求
v3: + prompt_manifest.json     ← 需要更多元数据（版本号、文件路径、启用/禁用、可编辑范围）
     - 但没删 v1/v2，说"向后兼容"
v4: + prompts/*.md             ← 内容从代码常量抽到独立文件
v5: + prompt_overrides.json    ← 另一个temporary hack（已死）
```

每一层都是**增量补丁**，不是**重构设计**。没人停下来把3个JSON合并成1个manifest，因为"能用就别动"——直到今天改错文件。

现在去掉最垃圾的那个（`overrides.json`）后还剩4个，其中前3个（order + visibility + manifest）从功能上确实可以合并成1个，只是`migrate_to_manifest.py`和`prompt_builder.py`的fallback路径依赖它们。**技术和历史包袱的差别。**
---
[Kirk]: ## 结论

`/root/.nanobot/` 下有 **3个活跃配置 + 7个备份残留 + 12个prompt内容文件**。备份残留全部零代码引用，可安全删除。

## 关键发现

**活跃配置（3个，都有用）：**

| 文件 | 大小 | 角色 | 被谁依赖 |
|---|---|---|---|
| `prompt_manifest.json` | 4.3KB | **唯一主配置源**（order/visibility/editability/phase/source_path/resolver） | prompt_builder.py |
| `prompt_order.json` | 318B | fallback（manifest不存在时用） | prompt_builder.py + migrate_to_manifest.py |
| `prompt_visibility.json` | 51B | fallback | prompt_builder.py + migrate_to_manifest.py |

**备份残留（7个，零引用，可删）：**

| 文件 | 大小 | 日期 |
|---|---|---|
| `prompt_order.json.backup_20260417` | 244B | 4/17 |
| `prompt_order.json.backup_20260417_v2` | 244B | 4/17 |
| `prompt_overrides.json.backup_20260417` | 8KB | 4/17 |
| `prompt_overrides.json.backup_20260417_v2` | 8KB | 4/17 |
| `prompt_overrides.json.backup_20260425_dynamic_profile` | 11KB | 4/25 |
| `prompt_v1_backup.json` ×2 | 8KB | 4/15（重复） |
| `prompt_visibility_v1_backup.json` ×2 | 51B | 4/15（重复） |

**12个 `.md` 文件**：`prompts/` 目录下，每个对应一个prompt section的实际内容，是必要的。

## 为什么分这么多文件

1. **历史迭代**：最初只有 `prompt_order.json`（纯顺序列表），后来需求扩展加了 `prompt_manifest.json`（带元数据的完整配置），但旧的没删因为 `migrate_to_manifest.py` 脚本还依赖它们作为输入
2. **备份没清理**：手动操作时留的 `.backup_*` 和 `_v1_backup` 文件，从未清理过
3. **12个md是必要的**：每个prompt section（main_prompt、memory、persona、hard_rules等）独立一个文件，方便单独编辑和版本控制

## 备注

- 7个备份文件占约36KB，代码零引用，删了零风险
- 如果要进一步精简活跃配置（3→1），需要先改 `migrate_to_manifest.py` 去掉对 order/visibility 的依赖，再删 fallback 逻辑——但这是更大的改动，之前你叫停过
