### 1. `component_manager.py` — 新增质量检查函数

```python
synthesis_quality_check(text) -> (bool, str)
```

三层启发式：
- **Tier 1**: 有 `##` 结构化标题？
- **Tier 2**: 元信息关键词（"问题已解答"/"无需补充"/"已交付"/"已完成"）占比>30%且无结构 → 拒绝
- **Tier 3**: 有具体证据（数字/URL/≥3个句子）？

最低长度阈值从150提升到 **400字符**。

### 2. `broadcast.py` 第1146-1176行 — 集成守卫

```
end_discussion → 长度检查(≥400) → 质量检查 → 通过才退出
```

质量检查失败时注入警告 + 具体失败原因，强制Leader重试。

| 输入 | 结果 |
|---|---|
| 空内容 | ❌ 拒绝 |
| "问题已解答，无需补充" | ❌ 拒绝（元信息） |

| 结构化总结（## 结论 + 数据 + URL） | ✅ 通过 |
| 无结构但有数字和多句话 | ✅ 通过 |
