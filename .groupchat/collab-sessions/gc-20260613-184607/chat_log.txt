[Harper]: 完全可行。核心思路：记录哪些参数被显式设置，构建时只传这些。

```python
from dataclasses import dataclass, field

@dataclass
class HyperParams:
    temperature: float = 1.0
    top_p: float = 0.9
    max_tokens: int = 2500
    top_k: int = 0
    frequency_penalty: float = 0.0
    presence_penalty: float = 0.0
    
    _set_fields: set = field(default_factory=set, repr=False)
    
    def __setattr__(self, name, value):
        super().__setattr__(name, value)
        if name != '_set_fields':
            self._set_fields.add(name)
    
    def to_dict(self, exclude_defaults=True):
        if not exclude_defaults:
            return {k: v for k, v in self.__dict__.items() if k != '_set_fields'}
        return {k: getattr(self, k) for k in self._set_fields}

# 用法
params = HyperParams()  # 全默认，不传任何东西
params.temperature = 0.8  # 显式设置，传temperature
params.max_tokens = 4000  # 显式设置，传max_tokens

print(params.to_dict())  # {'temperature': 0.8, 'max_tokens': 4000}
```

**关键点**：用 `__setattr__` 自动追踪哪些字段被写过，传参时只取这些。

如果只需字典版本，不需要类封装：

```python
class HyperParams:
    def __init__(self, **defaults):
        self._defaults = defaults
        self._values = {}
    
    def set(self, key, value):
        self._values[key] = value
    
    def to_dict(self):
        return dict(self._values)  # 只传显式set过的

# 用法
params = HyperParams(temperature=1.0, top_p=0.9, max_tokens=2500)
params.set('temperature', 0.8)
print(params.to_dict())  # {'temperature': 0.8}
```

[Harper]: 明白，默认字典包含所有键，传参时过滤掉默认值。

```python
from dataclasses import dataclass

@dataclass
class HyperParams:
    temperature: float = 1.0
    top_p: float = 0.9
    max_tokens: int = 2500
    top_k: int = None  # 无默认值时不传
    frequency_penalty: float = 0.0
    presence_penalty: float = 0.0
    
    DEFAULTS = {
        'temperature': 1.0,
        'top_p': 0.9,
        'max_tokens': 2500,
        'frequency_penalty': 0.0,
        'presence_penalty': 0.0,
    }
    
    def to_dict(self):
        """返回所有非默认值的参数"""
        return {k: v for k, v in self.__dict__.items() 
                if k != 'DEFAULTS' and k in self.DEFAULTS and v != self.DEFAULTS[k]}
    
    def to_full_dict(self):
        """返回完整字典（含默认值）"""
        return {k: v for k, v in self.__dict__.items() if k != 'DEFAULTS'}

# 用法
params = HyperParams(temperature=0.8, max_tokens=4000)
print(params.to_full_dict())   # {'temperature': 0.8, 'top_p': 0.9, 'max_tokens': 4000, 'top_k': None, 'frequency_penalty': 0.0, 'presence_penalty': 0.0}
print(params.to_dict())       # {'temperature': 0.8, 'max_tokens': 4000}  # 只传非默认
```

**关键点**：
- `to_full_dict()` = 默认全量字典
- `to_dict()` = 只传非默认值（0/None/默认不传）
