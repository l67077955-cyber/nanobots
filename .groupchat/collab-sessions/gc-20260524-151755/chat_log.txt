[Kirk]: ## 结论

**现有系统已支持 per-agent 独立 prompt，无需代码改动。** 每个 agent 目录下的 `INSTRUCTIONS.md` 就是独立 prompt — 独立存储、独立加载、只有该 agent 可见。

## 关键发现

| 需求 | 现状 | 是否满足 |
|------|------|---------|
| 独立 prompt 只有对应 agent 可见 | `INSTRUCTIONS.md` 从 agent 目录加载 | ✅ 已满足 |
| 独立 prompt 可自由编辑 | `editable_by: "agent"` 机制 | ✅ 已满足 |
| 全局 prompt 只有 leader 能编辑 | `editable_by: "global"` 不区分角色 | ❌ 需新增 `leader` 模式 |

**代码位置：**
- 加载：`agent_loader.py` L244-248
- 编辑权限：`prompt_builder.py` L208-212（解析）、L820-855（检查）
- 可见性过滤：`prompt_builder.py` L732-739

**如需限制全局编辑为 leader only**：在 `save_component_content` 中新增 `editable_by: "leader"` 分支，约5行代码。
