[Kirk]: 当前status box的问题：

```
┏━━ status ━━━━━━━━━━━━━━━━━━━┓
┃ ✅ 👑 Kirk  Done

```

**问题：**
1. 内容行右侧没有填充空格，导致右边界 `┃` 缺失（或对不齐）
2. "Kirk"和"Done"之间有**双空格**，不一致
3. 内容没有居中或左对齐的明确策略

**优化方案：**

```
┏━━ status ━━━━━━━━━━━━━━━━━━━┓
┃ ✅ 👑 Kirk Done              ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
```

改动：
- 双空格 → 单空格
- 内容行右侧补空格直到与底边对齐（左对齐+右填充）
- 保持box宽度30字符不变

如果要多agent场景，建议改成：

```
┏━━ status ━━━━━━━━━━━━━━━━━━━┓

```

每行固定格式：`┃ {状态emoji} {角色emoji} {名字}  {状态} {填充空格} ┃`，名字和状态列对齐。

[Kirk]: ## 结论

Status box的换行问题核心是**内容行右侧缺少空格填充导致`┃`边界缺失**，以及**双空格不一致**。

```
┏━━ status ━━━━━━━━━━━━━━━━━━━┓
```
