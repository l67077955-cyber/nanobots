## 停顿原因

`_auto_recall.py:90-94` 在群聊开始前会调用 LLM 生成检索关键词：

```python
result = await provider.chat_with_retry(
    messages=[{"role": "user", "content": prompt}],
    model=model,  # summarize_model
    max_tokens=300,
)
```

这个 LLM 调用完成后才会开始真正的群聊广播，造成用户感知的停顿。

## 可选方案

1. **禁用**：在 `run_loop.py:131-138` 加开关控制
2. **简化**：跳过 LLM 关键词生成，直接用原始 user_input 搜索
3. **异步化**：后台预加载，不阻塞首轮广播
4. **缓存**：对重复/相似问题复用之前结果
