## HsMod 迁移到另一台电脑

**需要复制的文件/文件夹（在你当前电脑的炉石安装目录下）：**

```
Hearthstone/
├── BepInEx/
│   ├── config/
│   │   ├── HsMod.cfg          ← 主配置
│   │   └── HsSkins.cfg        ← 皮肤配置
│   └── plugins/
│       └── HsMod.dll          ← 插件本体
├── doorstop_config.ini         ← BepInEx启动配置
└── winhttp.dll                 ← BepInEx代理DLL
```

**操作步骤：**

1. **旧电脑** — 找到炉石安装目录（通常是 `C:\Program Files (x86)\Hearthstone`），打包上述文件
2. **新电脑** — 先装好炉石，下载 [BepInEx_x86](https://github.com/BepInEx/BepInEx/releases) 解压到炉石目录
3. 把旧电脑的 `BepInEx/config/HsMod.cfg`、`HsSkins.cfg`、`BepInEx/plugins/HsMod.dll` 覆盖过去

核心就是两个 cfg 文件保留你的设置，其他都是通用组件。

    for /f "tokens=2*" %%a in ('reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\Hearthstone" /v InstallLocation 2^>nul') do set "HS_DIR=%%b"

    )

    pause
    exit /b 1

## 结论

**DRY参数只在本地推理后端（KoboldCPP、Oobabooga/text-generation-webui、TabbyAPI等）下才会显示。如果你用的是云端API（OpenAI、Claude、DeepSeek官方API、OpenRouter等），DRY参数不会出现。**

## 原因

DRY（Do-Not-Repeat-Yourself）是llama.cpp实现的采样器，需要后端在token级别做n-gram重复检测。云端API（OpenAI兼容格式、Claude原生格式）**不支持自定义采样器链**——采样完全在服务端完成，前端只能传temperature、top_p、max_tokens等标准参数，无法注入DRY。

## 你看不到DRY的可能原因

| 原因 | 概率 |
|---|---|
| **用的DeepSeek官方API/OpenRouter等云端接口** | 最高 |
| 后端版本太旧（KoboldCPP需较新版本才支持DRY） | 中 |
| SillyTavern版本过旧 | 低 |

## 解决方案

**方案A：用云端API时**——放弃DRY，改用Repetition Penalty（1.05-1.15）替代，效果差一些但能用。

**方案B：想要DRY**——切换到本地后端：
- **KoboldCPP**（推荐，最易上手）→ 下载最新版，加载DeepSeek V4 Flash的GGUF量化版
- **Oobabooga text-generation-webui**（需`--api`启动）
- **TabbyAPI** / **vLLM**

酒馆(SillyTavern)的"代理"有两种含义，设置方法完全不同：

---

### 一、网络代理（让酒馆通过代理访问外网API）

适用场景：国内访问OpenAI/DeepSeek等API需要翻墙。

编辑 `config.yaml`，找到 `requestProxy` 部分：

```yaml
requestProxy:
  enabled: true
  url: "socks5://username:password@127.0.0.1:1080"
  bypass:
    - localhost
    - 127.0.0.1
```

- **url** 支持 `socks5://`、`http://`、`https://` 协议
- **bypass** 是不走代理的地址列表
- ⚠️ `requestProxy` 与 `privateAddressWhitelist` 功能冲突，启用代理时需注意

---

### 二、反向代理（把酒馆暴露到公网/局域网）

适用场景：远程访问酒馆、手机访问电脑上的酒馆。

**第一步**：编辑 `config.yaml`

```yaml
listen: true
whitelistMode: false
basicAuthMode: true
basicAuth  username: "你的用户名"
  password: "你的密码"
```

**第二步**：Nginx 反代配置

```nginx
server {
    listen 443 ssl;
    server_name silly.yourdomain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket支持（酒馆需要）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

---

### 快速对照表

| 你想做什么 | 改哪个配置 |
|---|---|
| 酒馆访问API需要翻墙 | `requestProxy.enabled: true` + 填代理地址 |
| 局域网/公网访问酒馆 | `listen: true` + Nginx反代 |
| 只允许特定IP访问酒馆 | `whitelistMode: true` + 配置白名单 |
