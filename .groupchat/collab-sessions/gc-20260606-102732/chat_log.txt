## 🎴 新英雄：艾露恩 · 星界守望者

**英雄技能：星轨偏移 ⭐**
> **被动** — 每当你出售一个随从后，你在本回合的下一次刷新免费。

### 为什么符合要求？

**描述极简**：一句话——卖怪送一次免费刷新。

**不一般的操作空间**：
1. **电表倒转加速器**：配合霍格/海盗体系，卖海盗→免费刷→买→再卖→再免费刷……循环效率翻倍
2. **跳本神技**：前期卖个1本怪白嫖一次刷新找关键牌（比如5费回合卖1本怪找3本核心）
3. **理财收益最大化**：理财鱼/理财虎卖掉后免费刷一次，等于白赚经济
4. **铜须BUFF流**：卖战吼随从腾格子后免费刷新的同时还能继续找BUFF
5. **极限锁血操作**：残局时每卖一个废怪都能多一次搜key牌的机会

高手可以通过计算"卖谁、什么时候卖、刷到什么停"来打出远超普通玩家的节奏差。

## 新英雄设计：契约猎手（Cursed Broker）

**技能：[被动] 每当你购买一个随从，将它的一个友方随从变为金色（仅限当前回合）。**

### 简单描述的深层逻辑

表面上像是一个弱化版的"三连发现"——每回合只能变一个随从，而且是临时的。

但实际上：
1. **三连替代**：省去三连的麻烦，直接把已有随从变金
2. **卖金机制**：临时变金后再卖掉，可以获得三连价值的金币返还
3. **信息博弈**：对手无法预判你哪个随从会变金
4. **刷身材**：配合增益机制，变金随从在当回合可以吃到双倍光环效果

### 高端操作示例

```
前期：拿几个低星随从，不合成。技能触发后变金卖掉，净赚2-3金
中期：变金关键随从，当回合吃双倍buff，再卖掉保本
后期：三连变金+卖掉 = 白嫖一个金色随从的发现机会
```

这技能本身不强，但**配合延迟满足、配合信息差**可以打出很多脏活。

## 新英雄设计：回溯者（Riftwalker）

**技能：[消耗1] 移除一个友方随从。在下个回合开始时，将其移回战场，并获得「你本回合花费的金币」点属性。**

### 为什么符合这个风格

1. **时机窗口极短**：移除操作发生在战斗准备阶段，下回合才回来，中间有整整一回合的空窗期
2. **信息不对称**：对手不知道你移除了谁，不知道你花了多少钱，也不知道下回合会回来什么
3. **风险极高**：移除核心=赌命，对手可能趁虚而入
4. **操作密度大**：需要计算本回合花多少金、留多少金、什么时候移除、什么时候接回

### 高端操作链

```
第N回合：
├─ 卖掉杂毛，腾出格子
├─ 花6金买核心怪（此时已花6金）
├─ 移除核心怪（场上只剩垃圾）
└─ 对手以为你要死了，实际上...

第N+1回合开始：
└─ 核心怪回归，获得+6/+6（或更多）
```

### 反直觉博弈点

- 可以故意少花钱，让回来的怪变弱——**骗对手低估你**
- 可以故意多刷新，让回来的怪变强——**但自己也很脆弱**
- 可以连续两回合移除同一个怪——**叠加上限极高**
