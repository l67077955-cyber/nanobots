[Lucas]: **问题根因分析：**

Leader 在 `end_discussion` 时可能没有检查其他 agent 是否还在生成内容就直接移除。可能的场景：

1. Agent A 正在执行 tool_call（需要等待结果）
2. Leader 调用 end_discussion → 直接移除 Agent A
3. Agent A 的 tool 结果丢失，用户看不到完整输出

**潜在解决方案：**

| 方案 | 说明 |
|------|------|
| **A. Leader 端加锁** | end_discussion 前遍历 `_busy_agents`，等所有人完成再移除 |
| **B. Agent 端保护** | 被移除时自动 flush 待处理结果到 mailbox |
| **C. 双层确认机制** | Leader 发 "准备结束" → 各 agent 回复 "已完成" → Leader 才真正移除 |

从记忆中的 commit `19e9104` 看，之前修复过 agent 卡死的问题（空白期误判 busy），但可能没覆盖这个退出流程的竞态条件。
