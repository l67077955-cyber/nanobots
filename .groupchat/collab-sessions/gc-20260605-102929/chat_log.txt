[Harper]: ## MAI-Thinking-1 技术论文核心内容

**来源**: https://microsoft.ai/wp-content/uploads/2026/06/main_20260602_2.pdf

---

### 1. 模型架构
- **1T总参数量 / 35B活跃参数**，MoE，64专家/层，激活8个，56层，8k上下文
- 23B活跃参数的MAI-Base-1已超越DeepSeek-V3.2，仅用其62%活跃参数

### 2. 训练数据
- 自建爬取: 1.2T页面过滤至794B
- CommonCrawl: 242亿页面
- 主预训练30T tokens + 中期训练3.55T tokens

### 3. RL三阶段攀登

| 阶段 | 目标 | 核心特点 |
|------|------|----------|
| **STEM** | 数学/物理/化学/编程推理 | 数百万文档→5M+ QA对，多轮共识过滤，三阶段去污染 |
| **Agentic** | 多步工具调用/SWE | GitHub仓库→容器化环境，网络隔离/清除未来git commits防作弊 |
| **Helpfulness&Safety** | 人类偏好/指令遵循 | RM + AI Judge + 可验证奖励，Gated/Lexicographic组合 |

**通用RL配方**: 任务奖励 + 语言一致性奖励(防CoT混外语) - 长度惩罚(难题放宽、易题收紧)

### 4. 关键训练技巧
- **长度扩展课程**: 8k→128k渐进，早期省大量推理成本
- **top-p masking**: 防止backprop到采样外token导致训练发散
- **early-exit采样**: 先小批量探测通过率，决定是否继续，降低成本
- **STEM+Agentic联合**: 正向迁移，互相稳定

### 5. Benchmark结果
| 基准 | MAI-Thinking-1 | 对比 |
|------|---------------|------|
| AIME 2024 | 68.6% | 超DeepSeek-V3.2(61.1%) |
| FrontierMath | 25.2% | 最难子集13.2% |
| SWE-bench Verified | **52.3%** | 超Claude 3.7 Sonnet(46.6%) |
| GPQA Diamond | 58.7% | 超o1(54.1%) |
| Human preference vs Sonnet 4.6 | ~61%胜率 | |

[Kirk]: ## 结论

MAI-Thinking-1 是微软 MAI 团队发布的 SOTA 推理模型，基于 1T 总参数 / 35B 活跃参数的 MoE 架构，通过三阶段预训练 + 三路专家 RL 攀升训练而成。论文详细公开了从数据清洗、架构设计、训练工程到 RL 稳定性技巧的几乎所有细节。

## 关键发现

### 1. 模型架构
- **1T 总参数 / 35B 活跃参数**，MoE 架构，每层 64 个专家，激活 8 个
- **56 层**，上下文窗口 8,192 tokens（预训练阶段），后经 mid-training 扩展
- MAI-Base-1（23B 活跃参数）仅用 DeepSeek-V3.2 62% 的活跃参数，性能相当甚至超越

### 2. 预训练数据
- 自建网页爬取：初始 ~1.2T 页面 → 过滤后 794B 页面
- CommonCrawl 处理后：242 亿页面
- 数据清洗：去成人内容、盗版域名、AI 生成内容评分过滤
- **Main Pre-training**: 30T tokens（context 4096）
- **Mid-training 1**: 3.4T tokens（context 扩展到 65536）
- **Mid-training 2**: context 进一步扩展

### 3. RL 训练 — 三阶段攀登（核心创新）

**通用 RL 配方**：
- 奖励分解：R(q,y) = R_task(q,y) + w_lang · R_lang(y) − w_len · R_len(y)
- **语言一致性奖励**：检测 CoT 中的外语 token，防止长 context 下 logprob divergence 和训练不稳定
- **长度惩罚**：难题允许更长推理，简单题鼓励简洁
- **top-p masking**：防止 backprop 通过采样外 token，避免灾难性 off-policy mismatch
- **长度扩展课程**：8K → 128K 渐进扩展，显著降低早期训练成本

**Phase 1: STEM Climbing**（最长阶段）
- 解析教材/学术 PDF → 分层结构 → QA 配对 → 多轮 LLM 筛选 → 共识投票
- STEM Mix 数据集 >5M 样本，最难部分 >55 万 QA 对
- 数学、物理、化学、编程，含 SymPy 验证器、AI judge、代码测试
- 竞赛编程：16 万问题，17 种语言
- 三阶段去重：SHA-256 精确匹配 → MinHash 模糊匹配 → 向量嵌入相似度
- 对 benchmark 去污染

**Phase 2: Agentic Climbing**
- SWE 任务：从 487 万候选 → 26.5 万有效环境（94,044 独特仓库）
- 防 reward hacking：网络隔离、清除未来 git commits、重置测试文件、LLM 监控
- 合成数据：BugPilot / SWE-Smith / SWE-Mirror 从失败环境生成新问题
- General Tool Use：结构化工具调用，ReAct 风格编排

**Phase 3: Helpfulness & Safety Climbing**
- 奖励模型：基于 MAI-Base-1 微调预测人类偏好
- **Lexicographic reward shaping**：主要奖励相同时次要奖励才生效
- **Gated reward application**：安全不过关则不给质量分

### 4. 思考机制
- 使用 `thinking` 和 `answer` 标签格式
- 初始自蒸馏：prompt 模板引导模型先生成推理过程再回答
- 128K 最大输出长度

### 5. Benchmark 结果
| 基准 | MAI-Base-1 | 对比 |
|------|-----------|------|
| AIME 数学 | 68.6% | DeepSeek-V3.2: 61.1%, o1: 74.6% |
| FrontierMath | 25.2% | 最难子集: 13.2% |
| SWE-bench Verified | 52.3% | Claude 3.7 Sonnet: 46.6% |
| GPQA Diamond | 58.7% | o1: 54.1% |
| 人类偏好盲测 | ~61% 胜率 | vs Claude 3.5 Sonnet |

### 6. 关键训练洞察
1. **语言一致性奖励至关重要**：长 context 下模型在 CoT 中混入外语导致训练不稳定
2. **长度扩展课程**：8K→128K 渐进扩展，早期大幅节省推理成本
3. **top-p masking**：防止 off-policy mismatch
4. **STEM + Agentic 联合训练**：Agentic 正向迁移到 STEM，STEM 稳定 Agentic
5. **问题 pass-rate 过滤**：移除极低方差组，保留中等难度
6. **Gated/Lexicographic reward 组合**：解决不同奖励尺度不可比问题
