[Kirk]: ## C = Cloud Computing（云计算）

通过互联网按需提供计算资源（服务器、存储、数据库等），用户无需自建IT基础设施。

**CMHK场景：**
- 云网融合：5G网络与云服务深度结合，为企业提供一站式ICT解决方案
- MyLink平台的云端服务架构
- 企业客户的云迁移、云托管

**关键概念：** IaaS（基础设施即服务）、PaaS（平台即服务）、SaaS（软件即服务）

---

## E = Edge Computing（边缘计算）

将数据处理从中心云下沉到靠近数据源（基站、设备端）的边缘节点，降低延迟、减少带宽压力。

**CMHK场景：**
- 5G MEC（多接入边缘计算）：在基站侧部署计算能力，支持超低延迟应用（自动驾驶、远程手术、工业控制）
- 智慧城市：摄像头在边缘端完成AI推理，只回传结构化数据
- 网络切片：为不同业务分配独立计算资源

**核心优势：** 低延迟（<10ms）、高带宽效率、数据本地化（隐私合规）

---

## C和E的关系

| | Cloud（云） | Edge（边缘） |
|---|---|---|
| **位置** | 远端数据中心 | 靠近用户/设备 |
| **延迟** | 较高（50-100ms） | 极低（<10ms） |
| **算力** | 强，集中式 | 轻量，分布式 |
| **适合** | 大规模训练、存储 | 实时推理、响应 |

**一句话总结：** 云负责"重计算"，边缘负责"快响应"，两者协同构成5G+AICDE的基础设施底座。面试中可以说"Cloud and Edge are complementary — Cloud handles heavy workloads like model training, while Edge enables real-time inference at the network periphery."
