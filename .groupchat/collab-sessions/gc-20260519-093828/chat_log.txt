### 1. config.json 新增段

```json
{
  "tools": {
    "skills": {
      "always_override": {
        "debug": false,
        "settings": false,
        "cron": false
      }
    }
  }
}
```

**三级优先级**：`config.json override` → `SKILL.md frontmatter` → `loader.py 默认值(false)`

### 2. loader.py 改动点

`get_always_skills()` 第391-399行，加一行读取 config：

```python
def get_always_skills(self) -> list[str]:
    always = []
    # source 1: config.json overrides (highest priority)
    config_override = self.config.get("tools", {}).get("skills", {}).get("always_override", {})
    
    for name in self._list_skills():
        meta = self._get_skill_meta(name)
        if not meta:
            continue
        # source 2: SKILL.md frontmatter (fallback if not in config)
        is_always = config_override.get(name, meta.get("always", False))
        if is_always:
            always.append(name)
    return always
```
