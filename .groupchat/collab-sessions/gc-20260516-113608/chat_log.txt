**你的情况分析**：IANG签 + 之前学生签，有内地驾照。

**两条路：**

### 方案A：免试换领（推荐，你有内地驾照的话）

**条件**（满足任一即可）：
1. 内地驾照签发满 **5年**；**或**
2. 你在内地居住 ≥6个月期间考取的驾照；**或**
3. **你持有中国内地护照** ← 你百分百满足这条

**流程（2026年3月16日起新规）**：
1. **网上预约**：https://www.gov.hk/tc/residents/transport/drivinglicense/diabs.htm （必须预约，现场不设派筹）
2. 填 **TD63A表格**（运输署官网下载）
3. 准备材料：
   - 内地驾照原件+复印件（正反面）
   - 中国护照原件+复印件
   - 香港身份证原件+复印件
   - **3个月内住址证明** + **香港通讯地址证明**
   - 费用 ~$900港币
4. 按预约时间到运输署牌照事务处递交
5. 等通知领取正式驾照（约1-2周）

### 方案B：直接考试
无内地驾照/不满足免试条件 → 报名香港驾驶考试（笔试+路试，排队很久）

**明确结论**：你有内地驾照 + 中国护照 → **走免试换领方案A**，最快最省事。

## 无驾照 → 香港从零考驾照

---

### 📋 完整流程（5步）

```
网上申请学牌 → 笔试(电脑) → 学车练车 → 路试(乙+丙) → 领P牌 → 1年后换正式驾照
```

---

### ① 申请学习驾驶执照（学牌）

| 项目 | 详情 |
|---|---|
| **表格** | TD555（[官网下载](https://www.td.gov.hk/filemanager/tc/content_5118/td555_e-fillable_chi.pdf)） |
| **条件** | 年满18岁、持HKID、住址证明 |
| **费用** | 学牌 HKD **548** |
| **方式** | 运输署网上申请 或 到牌照事务处递交 |
| ⚠️ | 私家车需先参加**指定驾驶学院强制训练课程**才能领学牌 |

---

### ② 笔试（甲部试）

| 项目 | 详情 |
|---|---|
| **形式** | 20题电脑选择题，20分钟 |
| **及格** | 答对16题（80%） |
| **费用** | 考试排期费（路票）：HKD **510** |
| **预约** | 填TD82表格 或 [网上购买驾驶考试表格](https://www.td.gov.hk/sc/public_services/licences_and_permits/driving_test/roadtest.htm) |
| **资料** | 运输署道路使用者守则（官网有），淘宝/书店有题库 |

---

### ③ 学车训练

| 途径 | 总费用估算 | 特点 |
|---|---|---|
| **政府指定驾院**（香港驾驶学院等） | ~HKD 13,000 | 有自己考场，笔试路试可分开考，排期较快 |
| **私人驾校**（李健、铿锵、德安等） | ~HKD 7,700 | 灵活，口碑参差 |
| **个体师傅** | ~HKD 6,000 | 最便宜，靠口碑找，约课灵活 |

- 推荐训练时数：**30小时**以上
- 每节课（45分钟）：HKD 200-400
- 路试用车需自租

---

### ④ 路试（乙部 + 丙部）

| 乙部（场内） | 丙部（路面） |
|---|---|
| 侧方位停车 | 实际道路驾驶 |
| 窄路掉头 | 按指定路线行驶 |
| 斜坡起步 | 港岛/九龙/新界任选 |

> 港岛路线最难，九龙新界排期更长。**非政府驾院学员乙丙通常连考（合并试）**。

---

### ⑤ 领证

| 阶段 | 说明 |
|---|---|
| **路试合格** → 申领暂准驾驶执照（P牌） | 表格TD590，有效期12个月 |
| **P牌满1年无严重违规** → 正式驾照 | 表格TD557，有效期10年 |

---

### 💰 费用汇总

| 项目 | 金额 |
|---|---|
| 学牌费 | HKD 548 |
| 考试排期费（路票） | HKD 510 |
| 学车训练（个体师傅30h） | ~HKD 6,000-9,000 |
| P牌/正式驾照申领 | 各数百 |
| **总计** | **约 HKD 7,000-14,000** |

---

### ⏱️ 时间线

从报名到拿P牌：**通常6-12个月**（笔试排期1-3月 + 学车2-4月 + 路试排期3-6月）

---

**最短路径建议**：直接报香港驾驶学院（沙田/元朗/观塘），一站式搞定笔试+学车+路试，大约6-8个月、HKD 13,000左右搞定。
