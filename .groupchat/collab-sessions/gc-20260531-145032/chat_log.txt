## Grok Build 核心信息

**定位**：终端原生 agentic 编码工具，edit-run-test 完整循环

**架构**：
- 多代理：最多 8 个子代理并行，各自在隔离 git worktree 中工作
- Plan Mode：先出变更计划，用户审批后再执行
- Headless 模式：支持脚本/CI 驱动
- `/skillify`：将会话捕获为可重用技能

**兼容性**：AGENTS.md、MCP 服务器、hooks、plugins、skills — 基本复刻了 Claude Code 的生态

**模型**：`grok-build-0.1`，256K 上下文窗口

**价格**：
- SuperGrok Heavy：$300/月（首6月 $99/月）
- API：$1/百万输入 token，$2/百万输出 token

**安装**：
```bash
curl -fsSL https://x.ai/cli/install.sh | bash
```

**状态**：早期 beta，功能不完整，有已知问题。适合探索，生产环境建议等 GA。

---

和 nanobot 的群聊多代理架构思路类似，但 Grok Build 专注单仓库编码，nanobot 专注 Telegram 群聊协作。两者解决不同层面的问题。
