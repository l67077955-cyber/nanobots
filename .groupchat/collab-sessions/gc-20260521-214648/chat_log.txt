[Kirk]: ## 结论

轮数计算存在**不一致bug**：prompt显示 `[Round: N]`，但事件日志和round_summary记录的是 `round: N+1`，差1。

## 关键发现

- `engine._round` 在 `run_loop.py:128` 从 `rounds`（1-based）赋值，**已经是正确的轮数**
- `broadcast.py:454` 事件记录用了 `engine._round + 1` → 多加了1
- `broadcast.py:1672` `_save_round_summary` 也用了 `engine._round + 1` → 同样多加了1
- prompt显示正确（直接用 `engine._round`），只有日志/持久化层错了

## 修复

两行改动：
```python
# broadcast.py:454
"round": engine._round + 1,  →  "round": engine._round,
# broadcast.py:1672
round_num=engine._round + 1,  →  round_num=engine._round,
```

此bug从17号版本就存在，非新引入。
