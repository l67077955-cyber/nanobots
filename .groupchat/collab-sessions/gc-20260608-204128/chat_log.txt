[Kirk]: ## 结论

**根因找到了：`wait()` 的 proactive nudge 绕过了 rank 检查。**

打断有两条路径：
1. `chatroom_send` → `mailbox.send()` → `_try_interrupt()` → `_can_interrupt()` ✅ 有 rank 检查
2. `wait(from_agent=X)` → **直接 `evt.set()`** ❌ **无 rank 检查**（BUG）

`mailbox.wait()` 第 622-630 行有一段 "proactive nudge"：当等待的目标 agent 正在 busy 时，直接设置其 interrupt event 让它提前退出 tool_loop。这段代码**完全跳过了 `_can_interrupt()`**，导致任何低 rank agent 都能通过 `wait()` 打断高 rank agent。

**修复**（commit `f6842281`）：在 proactive nudge 前加 `_can_interrupt(agent_name, from_agent)` 检查。低 rank agent 调 `wait()` 等高 rank busy agent 时不再打断，改为 debug 日志记录。
