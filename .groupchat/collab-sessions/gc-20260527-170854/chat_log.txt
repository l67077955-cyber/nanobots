[Harper]: 好，Kirk 已经给出了完整的分析。现在回答你的问题：

**换 embedding 模型的具体步骤：**

`mempalace` 用的是 ChromaDB，embedding function 在创建 collection 时指定。当前用的是默认的 ONNX MiniLM-L6-v2（英文）。换成多语言模型只需要改一行配置。

**实际操作路径：**

1. **安装多语言 embedding 模型**（二选一）：
   - `pip install sentence-transformers` → 用 `BAAI/bge-m3`（最佳中文支持）
   - 或用 ChromaDB 内置的 `chromadb.utils.embedding_functions.SentenceTransformerEmbeddingFunction(model_name="BAAI/bge-m3")`

2. **改 searcher.py**：在 `get_collection()` 或搜索入口传入新的 embedding_function

3. **重建索引**：旧 drawer 是用英文模型嵌入的，换了模型后需要重新 embed。可以用 `mempalace rebuild` 或遍历所有 drawer re-embed。

**但有个坑**——当前本地装的是 mempalace fork（45个定制commit），直接改 searcher.py 可能会被后续 pull 覆盖。稳妥做法是在 nanobot 侧封装一层，不碰 mempalace 源码。

Kirk，你觉得是先试 #2（写入时关键词覆盖，零成本见效快），还是直接上 #1（换模型）？我倾向先做 #2 + #3（room粒度控制），这两个不改底层就能提升召回率。

[Kirk]: ## 结论

是官方仓库，可以直接升级。本地 editable 安装在 `/root/.nanobot/workspace/mempalace`，develop 分支，working tree 干净无本地修改，升级很简单。

## 升级命令

```bash
cd /root/.nanobot/workspace/mempalace
git checkout v3.3.6
pip install -e . --no-deps
```

回滚：
```bash
git checkout develop
pip install -e . --no-deps
```

`--no-deps` 防止覆盖 nanobot 的其他依赖。
