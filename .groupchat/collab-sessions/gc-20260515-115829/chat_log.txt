## #1 方案审查

### 问题 1：摘要累积（必须修）
每次 reactivation 注入一条 system 摘要，多次后 system 部分膨胀，**破坏前缀稳定性**。

**修复**：注入前检查 `messages[sys_msg_count]` 是否已是摘要 system msg，是则替换而非追加。

```python
# 注入摘要前
summary_idx = sys_msg_count
if (summary_idx < len(messages) and 
    messages[summary_idx].get("role") == "system" and
    messages[summary_idx].get("content", "").startswith("## 早期对话摘要")):
    messages[summary_idx] = summary_msg  # 替换
else:
    messages.insert(summary_idx, summary_msg)  # 首次注入
```

### 问题 2：LLM 调用失败 fallback（必须修）
`chat_with_retry` 可能抛异常（超时/rate limit），摘要失败时不能阻塞 agent 唤醒。

**修复**：try/except 包裹，失败时回退到纯切片丢弃（当前行为）。

### 问题 3：性能开销（建议优化）
每次 reactivation 都调 LLM 做摘要，如果 agent 频繁唤醒（如每 30s 收到消息），延迟叠加。

**建议**：加一个 `min_dropped` 阈值——丢弃消息数 < 5 条时不调 LLM，直接切片。小量丢弃不值得 LLM 调用。

## 前缀为什么不逐步增加**前缀不会逐步增加**是刻意设计，三层锁死：

1. **`_sys_msg_count` 快照**（broadcast.py:685）— agent 启动时记录 system messages 数量，此后 `messages[:_sys_msg_count]` 永不修改
2. **`prune_conversation_tail_with_summary`** 只裁剪 `messages[sys_msg_count:]` 对话尾部
3. **摘要替换而非追加**（tool_pruning.py:328-335）— 新摘要覆盖旧摘要，不增加前缀长度

## 当前上下文组织形式

```
messages = [
  system prompt (cache_control)  ← 前缀，永不增长
  tools (cache_control)
  memory)          ← 前缀
  [上下文摘要] (system)           ← 替换不追加
  ...最近 6 轮对话 (18 条)...
  [提醒] anti-repeat (system)     ← 去重后注入
  [队友消息] (user)
]
```

## 发现的问题

### 问题 1：两套压缩系统互不感知（硬伤）
- **HistoryContext**（context.py:154）压缩自己的 `self.messages 原始存储，≥21条数 ≥21 条时压缩中间段
- **broadcast**（tool_pruning.py:228）messages 对话 >18 条时裁剪+摘要

**后果**：broadcast 先裁剪到 ≤18 条 → HistoryContext 永远达不到 21 条阈值 → **HistoryContext 的 maybe_compress 压缩逻辑实际死代码**。两套摘要各自为政，信息不共享。

### 问题 2：anti-repeat 去重范围过窄（潜在 bug）
只检查 `messages[-6:]`（line 1304-1308）。如果 agent 在 reactivation 中执行了长工具链（>6 条消息），anti-repeat 被推出最近 6 条范围，下一轮会重复注入。

**修复**：检查范围扩大到 `messages[sys_msg_count:] 全量，或至少检查最近 18 条（6 轮）。

### 问题 3：HistoryContext 摘要格式与 broadcast 摘要格式不一致
- HistoryContext: `[早期对话摘要（压缩了 N 条中间消息）]`
- broadcast: `[上下文摘要 — 以下 N 条早期消息已被压缩]`

如果未来要合并两套系统，格式需要统一。

### 问题 4：无大问题
无问题的地方
- 前缀稳定性：✅ 三层锁死，不会增长
- 摘要替换逻辑：✅ 正确，不会累积
- anti-repeat 去重：✅ 逻辑正确（仅范围偏小
- 裁剪 fallback：✅ 保留最近 6 轮，摘要放前面
