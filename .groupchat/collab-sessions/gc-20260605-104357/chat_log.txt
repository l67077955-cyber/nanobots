[Kirk]: ## 结论

**含金量 8/10** — 当前最透明的 SOTA 推理模型技术报告，RL 训练工程细节的行业标杆。但"无合成数据"的边界定义有模糊空间，且闭源不可复现。

## 关键发现

### 真正高价值的部分

1. **零蒸馏 + 零合成数据**：整个 pipeline 不依赖任何第三方模型蒸馏，RL 从零开始学推理。DeepSeek-R1 用了蒸馏，OpenAI o1 不公开。这是目前唯一公开的"纯 RL from scratch"大模型训练全流程。

2. **RL 训练稳定性技术（最核心贡献）**：
   - **语言一致性奖励**：检测 CoT 中混入外语 token，解决长 context 下 logprob divergence 导致的训练崩溃
   - **top-p masking**：防止 backprop 通过采样外 token，避免灾难性 off-policy mismatch
   - **长度扩展课程**：8K→128K 渐进扩展，早期省大量推理成本
   - **Gated/Lexicographic reward 组合**：安全不过关则不给质量分，解决不同奖励尺度不可比问题
   - 这些是**解决实际训练崩溃的工程经验**，对从业者直接可用

3. **三阶段攀登框架**：STEM→Agentic→Helpfulness 渐进式 RL，比 DeepSeek-R1 的单阶段更系统化。且 STEM 和 Agentic 联合训练有正向迁移。

4. **数据工程全链路透明**：1.2T 页面→794B 过滤后→QA 提取→多轮 LLM 共识投票→三阶段去重→benchmark 去污染。每个环节有具体数字。

5. **基础设施透明度**：MFU 从 18%→22% 的优化过程（custom Triton kernel、ZeRO-2、block-sparse attention），GB200 集群配置，确定性训练（bitwise reproducible）。

### 中等价值

- **模型架构**：标准 MoE（1T/35B），无根本性创新，但 expert parallelism 64 + context parallelism 的工程细节有价值
- **Benchmark**：AIME 2025 97%、SWE-bench 52.3%，SOTA 但与 o3/GPT-5.1 差距不明（论文未对比）

### 存疑/低价值

- **"无合成数据"边界模糊**：论文声称不用合成数据，但数据清洗 pipeline 中大量使用 LLM 辅助（QA 提取、共识投票、rewrite），严格来说 LLM 生成的 QA 对就是合成数据，只是不来自第三方模型
- **人类偏好评估样本量有限**：仅与 Sonnet 4.6 对比，未与 o3、Gemini 2.5 Pro 等最新模型盲测
- **不可复现**：30T tokens + 8192 GPU 的训练成本，无人能独立验证
