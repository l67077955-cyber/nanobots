[Kirk]: ## 结论

Dynamic 组件显示"○空"是误报，不是真的空。

**根因**：pipeline 视图用 `get_component_template()` 查**静态模板文件**来判断内容。但 `skills_overview` 和 `examples` 是运行时动态生成的（`_build_skills_overview()` + agent 配置），根本没有静态模板文件，所以永远返回空。

**修复**：`settings.py` 第378-386行，对 `phase == "dynamic"` 的组件显示 `⚡动态` 标记：

```python
if phase == "dynamic":
    status = "⚡动态"
else:
    tpl = PromptBuilder.get_component_template(key)
    status = f"●{len(tpl):,}字" if tpl else "○空"
```
