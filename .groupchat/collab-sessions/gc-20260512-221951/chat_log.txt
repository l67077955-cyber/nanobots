[Kirk]: ## GeForce Now 取消订阅

### 方法一：NVIDIA 官网/应用（最通用）
1. 登录 [account.nvidia.com](https://account.nvidia.com) 或打开 GeForce Now 客户端
2. 进入 **Membership**（会员）页面
3. 找到当前订阅计划 → 点击 **Manage**（管理）
4. 选择 **Cancel Membership**（取消会员）
5. 确认取消

取消后**仍可使用至当前计费周期结束**，不会立即失效。

### 方法二：通过第三方商店订阅的
如果你是通过以下渠道订阅的，**必须回对应商店取消**，NVIDIA 官网无法操作：

| 订阅渠道 | 取消位置 |
|---|---|
| **Apple App Store** | 设置 → Apple ID → 订阅 → GeForce Now → 取消订阅 |
| **Google Play** | Play 商店 → 头像 → 付款与订阅 → 订阅 → GeForce Now → 取消订阅 |
| **Steam** | Steam 商店 → 账户详情 → 管理订阅 → 取消 |

### 注意事项
- 取消 ≠ 退款，已扣费用不退
- 免费层（Free tier）无需取消，不产生费用
- 如遇问题可联系 NVIDIA 客服：[nvidia.custhelp.com](https://nvidia.custhelp.com)
