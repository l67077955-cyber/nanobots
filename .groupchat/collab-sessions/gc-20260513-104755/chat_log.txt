[Kirk]: ## 结论

**memory_palace store 报错原因：Python 环境不匹配**

| 项目 | 值 |
|---|---|
| **报错** | `No module named 'mempalace.mcp_server'` |
| **根因** | mempalace 装在系统 Python (`/usr/bin/python3`)，但 nanobot 进程运行在 **pipx venv** (`/root/.local/share/pipx/venvs/nanobot-ai/bin/python`) |
| **已执行修复** | `venv_python -m pip install -e /root/.nanobot/workspace/mempalace` → 安装成功，venv 内验证可导入 ✅ |
| **仍需操作** | **重启 nanobot gateway 进程**，当前进程缓存了旧的 ImportError，新 import 不会生效 |

重启命令：
```bash
nanobot gateway restart
```
或手动 kill 后重新启动。重启后 memory_palace store 即可正常使用。
