[Kirk]: ## 结论

`forget` **没有独立的 SKILL.md**，但有内嵌的使用格式说明，和其他内置工具（exec、web_search 等）形式一致。

## 关键发现

- **forget 是内置工具**（`nanobot/tools/forget.py`），不是 skill，所以没有 `skills/forget/SKILL.md`
- 文档以两种形式存在：
  1. **源码 docstring**（L1-14）：开发者视角的用法说明
  2. **LLM 运行时自动加载的 description + parameters JSON Schema**：每次对话自动注入，LLM 直接可见
- 这与 exec、web_search 等内置工具一致——都靠 JSON Schema 描述参数
- 区别于 skill（cron、weather 等）有独立 SKILL.md 文件，需 `read_file` 读取后才注入上下文
