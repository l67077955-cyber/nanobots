## Skill 提示词编排模式

**结构**：三段式，极简

```
### Skill: [技能名]
[一句话描述：功能 + 何时使用]
[read_file skills/[技能名]/SKILL.md for full doc]
```

**例**：
```
### Skill: cron
Schedule reminders and recurring tasks. Use when the user asks for timers, periodic checks, scheduled notifications, or one-time delayed tasks.
[read_file skills/cron/SKILL.md for full doc]
```

### 设计逻辑

| 层 | 内容 | 目的 |
|---|---|---|
| **L1 标题** | `### Skill: xxx` | 快速扫描技能清单 |
| **L2 触发条件** | "Use when..." | 让agent判断何时启用，避免误调用 |
| **L3 文档引用** | `read_file .../SKILL.md` | 按需加载全文，不占用上下文token |

核心原则：**上下文只留触发器，全量文档存文件**。一段描述≈30词，每个skill只占3行，token开销≈50 tok。

### 两种变体

1. **普通skill** — 如上，有SKILL.md完整文档
2. **无文档脚本** — 直接从 `scripts/` 目录自动发现，不单独写SKILL.md：
   ```
   Undocumented scripts (auto-discovered from scripts/ dirs):
     - `quick_validate.py`
   ```

### 关键设计决策

- 把"何时用"写进描述而非放文档里 → agent不需要打开文件就知道触发条件
- SKILL.md 格式自由（无强制模板）→ 每个skill可以按自身复杂度决定文档结构
- 脚本自动发现 vs skill手动注册 → 简单的一次性操作用脚本，复杂流程用skill

**一句话总结**：触发器inline、文档lazy-load、脚本auto-discover。token效率最大化。
