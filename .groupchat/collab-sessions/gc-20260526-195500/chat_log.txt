[Harper]: **诊断：闪退的根因是管理员提权机制。**

拆解执行流程：

**步骤1** — 脚本以非管理员身份双击运行  
**步骤2**** — `net session` 失败（非 admin → errorlevel≠0）  
**步骤3** — 执行提权代码：
```
powershell -Command "Start-Process '%~f0' -Verb RunAs"
exit /b
```
**步骤4** — 原窗口弹 UAC 提权对话框，然后 `exit /b` **立刻关闭原窗口**

---

## 问题所在

**你看到的"闪退"就是原窗口关了，但新提权窗口的 UAC 弹窗可能在后面/另一个桌面，你没注意到。** 新窗口才是真正跑脚本的窗口。如果新窗口里也报错（比如备份目录找不到、炉石路径检测不到），它会显示错误并 `pause`，但那个窗口被原窗口关闭误导了，你可能直接忽略了。

**针对"游戏在 C 盘"的额外问题：**

炉石是 Battle.net 安装的，通常**不会**在 `HKLM\SOFTWARE\...\Uninstall\Hearthstone` 注册表路径下写入 InstallLocation。你的 C 盘炉石很可能装在了**非标准路径**（比如自定义安装、或通过 Battle.net 安装在 `C:\Program Files (x86)\...` 但被 Battle.net 客户端自己的目录映射了）。

脚本的 fallback 路径只检查了：
- `C:\Program Files (x86)\Hearthstone`
- `C:\Program Files\Hearthstone`
- `D:\Hearthstone`

如果你的炉石在**其他路径**（比如 `C:\Users\xxx\AppData\...` 或自定义位置），脚本就找不到，提权后的新窗口也会报错然后 pause 退出。

---

## 解决方案（三选一）

**方案 A — 直接右键以管理员身份运行**（绕开代码提权步骤，一步到位）

**方案 B — 手动指定路径**，先确认你的炉石实际安装位置，然后：
```
hsmod_restore.bat hsmod_backup "C:\你的实际炉石路径"
```

**方案 C — 检查备份文件夹是否存在**：确保脚本所在目录下有一个 `hsmod_backup` 文件夹（含 BepInEx/、doorstop_config.ini、winhttp.dll）。

---

## 快速验证方法

在 CMD（不是双击）中手动跑，可以看到完整输出：
```cmd
cd /d "脚本所在目录"
hsmod_restore.bat
```
这样窗口不会闪退，你能看到到底是哪一步报错。

[Kirk]: ## 结论

**闪退是正常行为，不是 bug。** 脚本检测到非管理员权限后弹出 UAC 提权，然后 `exit /b` 关闭原窗口——你看到的"闪退"就是这一步。真正执行脚本的新窗口被 UAC 弹窗挡在后面了。

## 关键发现

- **闪退原因**：`Start-Process '%~f0' -Verb RunAs` + `exit /b`，原窗口立即关闭，新窗口在 UAC 后面
- **路径检测缺陷**：Battle.net 安装的炉石不在 `HKLM\...\Uninstall\Hearthstone` 注册表路径下，`reg query` 大概率失败；fallback 只检查了3个硬编码路径，非标准安装位置会漏掉
- **备份目录**：默认找脚本同目录下的 `hsmod_backup` 文件夹，不存在也会报错退出

## 解决方案

1. **右键脚本 → 以管理员身份运行**（绕过代码提权，直接看到输出）
2. 或在 CMD 里手动跑：`cd /d "脚本目录" && hsmod_restore.bat`（窗口不会关，能看到完整报错）
3. 如果报炉石找不到，手动传路径：`hsmod_restore.bat hsmod_backup "C:\你的炉石实际路径"`
