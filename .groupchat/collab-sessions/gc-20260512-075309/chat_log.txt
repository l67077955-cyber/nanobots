[Kirk]: 两个 Bug 已修复：

**Bug 1 — `cannot access local variable 'PromptBuilder'`**
- 根因：`_on_callback()` 方法内的局部 `from ... import PromptBuilder` 让 Python 把整个方法中的 `PromptBuilder` 标记为局部变量，走 `pre:` 路径时未执行到该 import → `UnboundLocalError`
- 修复：将方法内的局部 import 改为纯注释，消除绑定副作用

**Bug 2 — `'list' object has no attribute 'items'`**
- 根因：`_send_agent_hyperparams_keyboard()` 的 `agent_hp` 参数在某些情况下是 list 而非 dict
- 修复：函数入口加类型守卫 `if not isinstance(agent_hp, dict): agent_hp = {}`，集中防护无需逐调用点修改
