# CS基础知识点 · 按重要性四梯队排序

## 🔴 第一梯队（必背，命中率最高，5分钟过完）

**1. TCP拥塞控制四算法**
- 慢开始：cwnd从1开始，每RTT翻倍（指数增长）
- 拥塞避免：cwnd达到ssthresh后，每RTT+1（线性增长）
- 快重传：收到3个重复ACK立即重传
- 快恢复：快重传后ssthresh=cwnd/2，cwnd=ssthresh（不回到1）
- ⚠️ CSMA/CD不是TCP算法！数据链路层协议

**2. 死锁四条件**
- 互斥、持有并等待、不剥夺、循环等待
- 预防：破坏任一条件
- 避免：银行家算法
- Belady异常：仅FIFO有

**3. 稳定排序 vs 不稳定排序**
- ✅稳定：冒泡、插入、归并、计数、基数
- ❌不稳定：选择、快排、堆排、希尔
- n小时(<50)或基本有序：插入排序最快
- 快排最坏：已排序/逆序

**4. 事务隔离级别（弱→强）**
- READ UNCOMMITTED → RC → **RR(MySQL默认)** → SERIALIZABLE
- 脏读：RU级别
- InnoDB RR通过MVCC+间隙锁部分解决幻读

**5. InnoDB vs MyISAM**
- InnoDB：事务✅ 行锁✅ 外键✅ 崩溃恢复✅
- MyISAM：全❌，但count(*)快、支持全文索引

**6. HTTPS加密流程**
- **非对称交换对称密钥，对称加密正文**（别搞反！）
- 流程：TCP→TLS握手(ClientHello→ServerHello→证书→密钥交换→Finished)→HTTP

## 🟠 第二梯队（高频，再花5分钟）

**7. 页面置换算法**
- OPT > LRU ≈ Clock > FIFO
- FIFO唯一有Belady异常

**8. 进程 vs 线程**
- 进程：资源分配最小单位
- 线程：CPU调度最小单位
- 线程共享：代码段、数据段、堆、文件描述符
- 线程私有：栈、寄存器、PC、线程ID

**9. IPC方式（快→慢）**
- 共享内存 > 管道 > 消息队列 > 信号量 > Socket

**10. HTTP状态码**
- 200 OK | 301永久重定向 | 302临时 | 304未修改
- 400 Bad Request | 401未认证 | 403无权限 | 404 Not Found
- 500服务器错误 | 502 Bad Gateway | 503不可用 | 504网关超时

**11. B+树 vs B树**
- B+树：数据全在叶子、叶子链表串联、范围查询快
- **MySQL索引用B+树**（不是B树）

**12. 索引失效场景**
- 对索引列用函数、隐式类型转换
- LIKE '%xx'（左模糊）
- OR中有非索引列
- != / NOT IN

## 🟡 第三梯队（中等频率，快速扫一眼）

**13. 进程调度**
- SJF平均等待最短但可能饥饿
- 解决饥饿：老化(aging)
- RR时间片太大→FCFS，太小→切换开销大

**14. 虚拟内存**
- 映射单位：页(page)
- TLB加速页表查找
- 抖动：频繁缺页，解决：减少并发进程数

**15. DNS解析链**
- 浏览器缓存→OS缓存→本地DNS→根→TLD→权威
- DNS用UDP端口53

**16. TCP三次握手/四次挥手**
- 三次握手防已失效连接请求
- 四次挥手：TIME_WAIT等2MSL
- TCP首部最小20字节，UDP 8字节

**17. Python GIL**
- 同一时刻只有一个线程执行Python字节码
- CPU密集型多线程无效，用多进程

**18. EXPLAIN type（优→劣）**
- system > const > eq_ref > ref > range > index > ALL

## 🟢 第四梯队（偶尔考，有时间再看）

**19. 文件系统**
- inode存属性+数据块指针（不存文件名）
- 硬链接共享inode，不能跨文件系统
- 软链接独立inode，存路径字符串

**20. 图算法**
- Dijkstra不能处理负权边
- Floyd可处理负权边（不能有负权环）
- 最小生成树：Kruskal(边排序+并查集) / Prim(从点扩展)

**21. 哈希冲突**
- 链地址法 vs 开放寻址法
- 装载因子超阈值需扩容

**22. ARP/ICMP/NAT**
- ARP：IP→MAC，广播请求单播响应
- ICMP：ping用，网络层
- NAT：私有IP↔公网IP，NAPT用端口号区分
