## MAI-Thinking-1 数据集详细信息

### 一、预训练数据（Pre-training Data）

**数据来源**：
- **自建爬虫**：初始抓取约 **1.2万亿页面**，经过多层过滤后保留 **7940亿页面**
- **CommonCrawl**：处理后约 **242亿页面**
- 两者混合构成预训练语料

**数据清洗流程**（多层过滤）：
1. **去成人内容**：基于 URL 黑名单 + 内容分类器
2. **去盗版域名**：已知盗版站点黑名单
3. **AI 生成内容评分过滤**：用分类器识别并降低 AI 生成内容的权重
4. **质量评分**：基于困惑度、语言模型打分等多维信号
5. **去重**：三阶段 — SHA-256 精确匹配 → MinHash 模糊匹配 → 向量嵌入相似度

**训练规模**：
| 阶段 | Token数 | Context长度 |
|------|---------|------------|
| Main Pre-training | **30T tokens** | 4,096 |
| Mid-training 1 | **3.4T tokens** | 65,536 |
| Mid-training 2 | 扩展至 128K | 128,000+ |
| **总计** | **~33.55T tokens** | — |

**数据配比**：论文未公开各数据源的精确权重比例（保密）

---

### 二、STEM Climbing 数据集

**数据来源**：教材、学术论文 PDF、竞赛题目、在线课程

**数据处理 Pipeline**：
1. **PDF 解析** → 分层结构提取（章节→小节→段落）
2. **QA 配对**：用 LLM 从文本中提取问题和答案
3. **多轮 LLM 筛选**：多个 LLM 独立评估 QA 质量，**共识投票**决定保留
4. **三阶段去污染**：对已知 benchmark 做精确匹配 + 模糊匹配 + 语义去重

**数据集规模**：
- **STEM Mix 总数据集**：**>500万 QA 对**
- **最难部分**（高难度推理）：**>55万 QA 对**
- 涵盖学科：数学、物理、化学、编程
- **竞赛编程**：16万问题，支持 **17种编程语言**

**验证机制**：
- **数学**：SymPy 符号计算验证器
- **编程**：代码测试用例验证
- **通用推理**：AI Judge 评估

---

### 三、Agentic Climbing 数据集

**SWE 任务数据**：
- **GitHub 仓库候选**：487万个
- **有效环境构建**：26.5万个（可容器化、可测试）
- **独特仓库数**：94,044个
- 每个仓库构建 Docker 容器化环境，含测试框架

**防作弊措施**：
- 网络隔离（容器内无外网）
- 清除未来 git commits（防止模型记住答案）
- 重置测试文件到原始状态
- LLM 监控 reward hacking 行为

**合成数据增强**（论文称"非合成"，但本质是 LLM 辅助生成）：
- **BugPilot**：从失败环境中自动生成新的 bug 修复问题
- **SWE-Smith**：基于仓库上下文生成 SWE 问题
- **SWE-Mirror**：镜像已有问题生成变体

**General Tool Use 数据**：
- 结构化工具调用场景
- ReAct 风格编排
- 多步工具链任务

---

### 四、Helpfulness & Safety 数据集

**数据来源**：
- 人类偏好标注（基于 MAI-Base-1 生成样本）
- 红队测试数据
- 安全边界案例

**奖励模型训练数据**：
- 基于 MAI-Base-1 微调的 RM
- 预测人类偏好排序
- 安全分类器训练数据

---

### 五、关键数据工程细节

**去重体系**（贯穿所有阶段）：
1. **SHA-256 精确去重**：完全相同的文档
2. **MinHash 模糊去重**：近似重复文档
3. **向量嵌入相似度去重**：语义相似文档
4. **Benchmark 级别去污染**：对 AIME、GPQA、SWE-bench 等测试集做专门过滤

**质量筛选**：
- 多轮 LLM 共识投票（≥2/3 通过）
- Pass-rate 过滤：移除极低通过率的样本组
- 保留中等难度样本（太难或太简单都降低权重）
