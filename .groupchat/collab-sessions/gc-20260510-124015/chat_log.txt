## 🔵 CS基础必背

**OS：**
- 死锁四条件：互斥、持有等待、不剥夺、环路等待
- 虚拟内存映射单位：**页(page)**
- IPC最快：共享内存 > pipe > socket > signal
- fork()返回值：父进程返回子PID(正数)，子进程返回0，出错-1
- SJF缺点：饥饿；现代OS用CFS/多级反馈队列
- 页面置换：OPT>LRU≈Clock>FIFO；Belady异常仅FIFO

**数据结构：**
- 稳定排序：归并✓ 冒泡✓ 插入✓ | 不稳定：快排× 选择× 希尔×
- AVL查找：O(log n)
- 哈希冲突：链地址法 vs 开放寻址

**数据库：**
- MySQL索引底层：**B+Tree**（不是B-Tree）
- 隔离级别弱→强：READ_UNCOMMITTED→RC→RR→SERIALIZABLE
- 脏读：READ_UNCOMMITTED级别
- EXPLAIN type最优→最劣：system > const > eq_ref > ref > range > index > **ALL**
- UNION去重有开销，不需要去重用**UNION ALL**
- MyISAM：不支持事务/行锁/崩溃恢复 | InnoDB：全支持

**网络：**
- TCP拥塞控制四算法：慢开始、拥塞避免、快重传、快恢复（**不含CSMA/CD**）
- 502=Bad Gateway，503=Service Unavailable（503不是网关超时）
- DNS解析链：HOSTS→本地缓存→LDNS→根→TLD→权威
- HTTPS：**非对称交换密钥，对称加密正文**（别搞反）
- SYN Flood：半连接队列占满，防御用SYN Cookie

- DL vs ML核心区别：DL不需手动特征提取

**模板1：最长公共前缀**
```python
def longestCommonPrefix(strs):
    res = ""
    for chars in zip(*strs):
        if len(set(chars)) != 1: break
        res += chars[0]
    return res
```

**模板2：LRU缓存**
```python
class LRUCache:
    def __init__(self, cap):
        self.cap = cap; self.dic = {}
    def get(self, k):
        v = self.dic.pop(k, None)
        if v is None: return -1
        self.dic[k] = v; return v
    def put(self, k, v):
        self.dic.pop(k, None); self.dic[k] = v
        if len(self.dic) > self.cap:
            del next(iter(self.dic))
```

**模板3：TopK频率**
```python
from collections import Counter; import heapq
def topK(nums, k):
    return [n for n,_ in heapq.nlargest(k, Counter(nums).items(), key=lambda x:x[1])]
```

**模板4：二分查找**
```python
def lower_bound(arr, t):
    l, r = 0, len(arr)-1
    while l <= r:
        mid = (l+r)//2
        if arr[mid] < t: l = mid+1
        else: r = mid-1
    return l
```
