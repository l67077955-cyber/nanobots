## 结论

**是的，Self/Final 消息只显示给用户，不进入其他 agent 的 mailbox。** 用户观察完全正确。

## 关键发现

两条独立路径：

1. **显示路径**（broadcast.py L1215-1237）：agent 没用 `chatroom_send` 时，系统显示 `┄ Agent → Self/Final ┄`，日志明确标注 `[Local Only]`。这只是 `_send()` 发到用户界面，不经过 mailbox。

2. **隐式广播路径**（broadcast.py L1042-1052）：agent 没用 `chatroom_send` 时，系统自动把文本通过 `mailbox.send()` 发给其他 agent。**但 L1048-1050 有限制**：
```python
if leader_name and name != leader_name:
    _implicit_targets = [leader_name]  # 队友只发给 Leader
```

所以实际效果：
- Harper 的 Self/Final → 用户能看到 ✓，mailbox 只发给 Kirk ✓
- Lucas 的 Self/Final → 同上 ✓
- **Harper 和 Lucas 互相看不到对方的 Self/Final** ✓

## 备注

**设计意图**：避免队友间的隐式广播唤醒正在 `wait()` 的队友导致死循环。如果队友想互相通信，必须显式用 `chatroom_send(to="All")`。这不是 bug，是有意为之的防御性设计——但副作用是队友间信息不透明。
