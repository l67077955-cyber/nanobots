[Kirk]: ## 结论

`forget` 功能可用，**按索引删除可靠，按关键词删除受限**。

## 关键发现

| 操作方式 | 结果 | 说明 |
|---|---|---|
| `indices=[0,1]` | ✅ | 按索引删除，支持数组一次删多条 |
| `indices=[0]` | ✅ | 单条删除 |
| `indices=[0,1,2,3,4]` | ✅ | 批量删除5条 |
| `keywords="科技"` | ❌ | 关键词匹配**工具名+参数**，不匹配返回内容 |
| `keywords="web_search"` | ❌ | 已被forget的条目被排除，只匹配当前批次剩余 |

**核心要点：**
1. **`indices` 是主力用法**：0-based，基于上一批次的工具调用，支持数组批量删除
2. **`keywords` 是辅助**：匹配的是调用签名（如 `curl xxx`），不是返回结果内容
3. **删除后索引偏移**：删掉 index 0 后，原 index 1 变成新 index 0
4. **返回确认**：`✓ forgot: <工具名>×<数量>`
