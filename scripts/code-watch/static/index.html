    网页里和 Grok Build 对话

    code-watch 只看 git；要浏览器里持续对话 agent，用 Grok Build 的远程通道：

    1. grok agent serve --bind 127.0.0.1:PORT --secret TOKEN — 本地 WebSocket，自建前端连上来
    2. grok agent headless --grok-ws-url wss://relay/ws — agent 连 relay，浏览器也连同一 relay（适合公网）
    3. grok -p "..." — 单次 headless prompt，适合脚本

    与 nanobot gateway 独立；可并行跑：gateway 处理 Telegram，Grok serve 处理网页调试。
